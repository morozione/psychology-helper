# Feature: Problem Tracking

## Status: planned

## Description
Track identified problems with statuses. Receive daily hints and guidance on how to work through each problem.

## User Stories
- [ ] As a user, I can see all my problems with their statuses
- [ ] As a user, I can view details of each problem
- [ ] As a user, I receive daily hints for active problems
- [ ] As a user, I can mark a problem as resolved
- [ ] As a user, I get notifications with daily hints

## Problem Statuses
| Status | Description |
|--------|-------------|
| `active` | Currently working on this problem |
| `in_progress` | Making progress, partially addressed |
| `paused` | Temporarily not focusing on this |
| `resolved` | Problem has been solved |

## Screens

### Screen: Problems List
- **Route**: `/problems`
- **Components**:
  - Filter tabs (All, Active, Resolved)
  - Problem cards with status badge
  - FAB to start new investigation
- **Behavior**:
  - Tap card to open Problem Detail
  - Swipe actions for quick status change

### Screen: Problem Detail
- **Route**: `/problems/{id}`
- **Components**:
  - Problem title and description
  - Status selector
  - Today's hint card
  - Hint history list
  - "Get New Hint" button
  - Related check-in history
- **Behavior**:
  - Daily hint generated by AI
  - Can manually request new hint

## Data Model
```kotlin
data class Problem(
    val id: String,
    val odId: String,
    val title: String,
    val description: String,
    val status: ProblemStatus,
    val hints: List<Hint>,
    val createdAt: Timestamp,
    val updatedAt: Timestamp,
    val resolvedAt: Timestamp?
)

data class Hint(
    val id: String,
    val content: String,
    val createdAt: Timestamp,
    val wasHelpful: Boolean?  // user feedback
)

enum class ProblemStatus {
    ACTIVE,
    IN_PROGRESS,
    PAUSED,
    RESOLVED
}
```

## Firebase Collection
```
users/{odId}/problems/{problemId}
  - title: String
  - description: String
  - status: String
  - createdAt: Timestamp
  - updatedAt: Timestamp
  - resolvedAt: Timestamp?

users/{odId}/problems/{problemId}/hints/{hintId}
  - content: String
  - createdAt: Timestamp
  - wasHelpful: Boolean?
```

## Gemini API - Hint Generation
```kotlin
val hintPrompt = """
Generate a helpful, actionable hint for someone working on this problem:
Problem: {problem_title}
Description: {problem_description}
Previous hints: {previous_hints}

Guidelines:
- Be specific and actionable
- Suggest one small step they can take today
- Be encouraging but realistic
- Keep it to 2-3 sentences
"""
```

## Notifications
- Daily notification at user-preferred time
- Contains hint for one active problem (rotating)
- Tap opens Problem Detail screen

## Implementation Notes
- Generate hints using Gemini API
- Cache today's hint locally
- Use WorkManager (Android) / BackgroundTasks (iOS) for notifications
- Track hint helpfulness for future AI improvements
