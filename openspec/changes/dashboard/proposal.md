# Proposal: Dashboard

## What
Main screen after login showing overview of user's problems and entry point to investigate new problems.

## Why
- Users need a central hub to see their progress
- Quick access to start problem investigation
- Overview of active problems motivates engagement
- Navigation to other app sections

## Scope
- Greeting header with user profile
- "Investigate Problem" primary action button
- Active problems list with status
- Bottom navigation bar

## Out of Scope
- Complex analytics/charts
- Problem editing from dashboard
- Notifications center

## Success Criteria
- User can see their active problems
- User can start investigating a new problem
- User can navigate to profile
- User can tap on a problem to see details
