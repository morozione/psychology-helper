# Proposal: Problem Investigation

## What
AI-powered chat to help users identify and articulate their problems. A short conversation (3-4 messages) that ends with a summary and generates a list of topics to work on.

## Why
- Users often struggle to articulate their problems clearly
- AI-guided conversation helps users explore their thoughts
- Structured output creates actionable problem list
- Short conversation prevents overwhelm

## Scope
- Chat interface with AI (Gemini 2.5)
- 3-4 message exchanges
- Automatic summary generation
- Problem identification and confirmation
- Save problems to Firestore

## Out of Scope
- Extended therapy conversations
- Voice input
- Image/media sharing
- Chat history browser

## Success Criteria
- User can describe their problem in a chat
- User receives helpful clarifying questions from AI
- User gets a summary after 3-4 exchanges
- User sees and confirms identified problems
- Problems are saved with "active" status
