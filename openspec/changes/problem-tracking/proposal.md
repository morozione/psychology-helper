# Proposal: Problem Tracking

## What
Track identified problems with statuses. Receive daily hints and guidance on how to work through each problem.

## Why
- Users need visibility into their progress
- Daily hints keep users engaged and moving forward
- Status tracking provides sense of accomplishment
- Actionable guidance makes problems manageable

## Scope
- Problems list with filter tabs
- Problem detail screen with hints
- Status management (active, in_progress, paused, resolved)
- AI-generated daily hints
- Hint history and helpfulness feedback

## Out of Scope
- Problem sharing with others
- Therapist/coach integration
- Complex analytics
- Problem categories/tags

## Success Criteria
- User can see all problems with statuses
- User can view details of each problem
- User receives daily hints for active problems
- User can mark problems as resolved
- User can rate hint helpfulness
