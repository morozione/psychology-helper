# Proposal: Daily Check-in

## What
Daily AI-guided check-in where the app asks questions about user's progress and emotional state.

## Why
- Regular check-ins build habit and engagement
- Tracking mood/progress reveals patterns over time
- AI personalization based on active problems
- Streak mechanics increase retention

## Scope
- 2-3 daily questions from AI
- Mood/progress tracking
- Check-in history with calendar
- Streak tracking
- Daily notifications

## Out of Scope
- Complex analytics/visualizations
- Export of check-in data
- Sharing progress with others
- Multiple check-ins per day

## Success Criteria
- User receives daily check-in prompt
- User answers AI questions about their day
- User can see check-in history
- User can see patterns/trends over time
- Streak is tracked and displayed
