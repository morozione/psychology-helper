# Proposal: User Profile

## What
User profile screen showing account info, statistics, and sign-out option.

## Why
- Users need to see their account details
- Statistics motivate continued engagement
- Sign-out functionality required for account switching
- Central place for user-related settings

## Scope
- Profile picture and name from Google
- Email display
- Problem-solving statistics
- Sign-out button

## Out of Scope
- Profile editing (name comes from Google)
- App settings (notifications, theme)
- Data export
- Account deletion

## Success Criteria
- User can view their profile information
- User can see Google account details
- User can see problem-solving statistics
- User can sign out
